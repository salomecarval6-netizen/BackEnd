A .gitkeep file is a placeholder file used by developers to force Git to track and maintain an otherwise empty directory in a repository.

The Problem It Solves:
By design, Git only tracks files (and the directory paths leading to those files); it does not track completely empty directories. 
If you create an empty folder in your project and try to commit it, Git will completely ignore it, and it won't be pushed to platforms like GitHub.
Adding a .gitkeep file makes the folder technically "not empty," which tricks Git into tracking the directory

Nodemon is a tool that speeds up Node.js development by watching your files and automatically restarting your server when it detects code changes. It replaces the node command so you do not have to manually stop and restart your app every time you save a file.

Installation:
Install globally: npm install -g nodemon
Install as a dev dependency: npm install --save-dev nodemon



Running Your App:
Run directly: nodemon server.js
Run local install via npx: npx nodemon server.js
Add to package.json scripts:  "dev": "nodemon src/index.js" then run npm run dev
