A .gitkeep file is a placeholder file used by developers to force Git to track and maintain an otherwise empty directory in a repository.

The Problem It Solves:
By design, Git only tracks files (and the directory paths leading to those files); it does not track completely empty directories. 
If you create an empty folder in your project and try to commit it, Git will completely ignore it, and it won't be pushed to platforms like GitHub.
Adding a .gitkeep file makes the folder technically "not empty," which tricks Git into tracking the directory
