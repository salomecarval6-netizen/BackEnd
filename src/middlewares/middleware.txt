In Express, a middleware is a function that sits between an incoming request and your final route handler. It has full access to the request object (req), the response object (res), and the next middleware function in the application’s request-response cycle.

The Middleware Core Signature:
Every middleware function takes exactly three arguments (four if it is an error-handling middleware):

function myMiddleware(req, res, next) {
    // 1. Logic happens here (e.g., checking tokens, formatting strings)
    
    // 2. You MUST either call next() or send a response!
    next(); 
}


The Generic Anatomy & Syntax of Global Middleware:
app.use(( req, res, next) => {
    // 1. Read or modify data here
    console.log(`Incoming: ${req.method} request to ${req.url}`);
    
    // 2. Pass control to the next function in line
    next(); 
});


req (Request Object): Contains all information about the incoming client (headers, URL, body data, cookies). Middleware can mutate this object to attach data for downstream routes (e.g., attaching req.user).

res (Response Object): Used to send data back to the client if the middleware decides to block the request (e.g., res.status(401).send("Unauthorized")).

next (Next Function Functionality): This is a mandatory callback function. Calling next() tells Express, "I am done with my checks; hand this request over to the next middleware or route handler in the execution chain." If you forget to call next(), your server will hang indefinitely and the request will time out.


1. Built-in Middleware:
These come packaged directly inside Express. You don't need to download external packages to use them.
express.json(): Parses incoming JSON request payloads.
express.urlencoded(): Parses incoming URL-encoded form submissions.
express.static(): Directly serves public files like images, CSS, or text documents.

2. Third-Party Middleware
Packages built by the developer community that you install via npm to solve common backend tasks.
cors(): Manages Cross-Origin permissions.
cookie-parser(): Translates secret browser cookies into readable JavaScript objects.
morgan(): Logs details of incoming requests directly to your terminal.

3. Router-Level / Route-Specific Middleware
Unlike global middleware (which run on every single button click or page visit), these are hand-picked to run only on highly specific endpoints

4. Error-Handling Middleware
These are unique safety-net catchers defined at the very bottom of your file structure. Express natively recognizes them because they accept four arguments instead of three: (err, req, res, next).
